**Make a style from a video** in Settings › Styles, with or without a film open. It used to say "Open a film first." With no film open, the editor makes the style on its own, using the editor and speed you set for new films. It shows under Your styles while it's being made. If the editor has a question about it, like which font to use for titles, you answer it right there in the row.

**Crash and freeze reports** you choose to send now point to the exact place in Direction where something went wrong, so problems get fixed faster.
